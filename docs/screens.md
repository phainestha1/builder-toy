- **원본:** [Figma — 아정당 미니 — M1 화면 설계](https://www.figma.com/design/VKhka0fEffMIDhOA0hgfHc) (페이지 2개: `고객 화면` — 01~04, `상담원 어드민` — 05)

- **작성:** 2026-10-05, `ajd:design` (T-C1)
- **주의:** 데모 수준입니다. 요금제, 금액, 고객 정보는 모두 예시 데이터입니다.

이 파일은 요약입니다. 내용이 다르면 Figma 원본이 맞습니다.

## 화면 흐름
```
고객:   01 랜딩(A/B) → 02 요금제 비교 → 03 지원금 계산기 → 04 상담 접수
                  └──────────────→ 03 (랜딩에서 바로 계산기로 갈 수 있음)
상담원: 05 상담원 어드민 (로그인 → 접수 목록 → 상세에서 상태 변경·지급 처리)
```
고객 화면은 모바일(375px), 어드민은 데스크톱(1440px) 기준입니다.

## 화면별 Before → After
| # | 화면 | Before | After |
|---|---|---|---|
| 01 | 랜딩 | "최대 지원금!" 문구, 배너, 회색 [상담 신청하기]. 금액은 "상담 시 안내" | 소구점 A안("최대 45만 원 받아요") / B안("위약금까지 보전해 드려요"). 주 버튼 [내 지원금 계산하기], 보조 버튼 [요금제 먼저 비교하기]. "개통 완료 후 지급", "계산할 때 연락처 안 받음" 안내 |
| 02 | 요금제 비교 | 요금제 이름과 월 요금, "지원금: 상담 시 안내", [상담 신청] | 속도 칩(전체/100M/500M/1G), TV 포함 칩, 기본 정렬 "예상 지원금 높은 순". 카드마다 월 요금과 예상 지원금, [이 요금제로 계산하기] |
| 03 | 지원금 계산기 | 없음 (상담원이 전화로 안내) | 입력: 요금제, 약정 남았는지(네/아니요), 남은 개월 수, 예상 위약금(모르면 평균값). 결과: 기본 지원금 + 위약금 보전(한도 30만 원) = 총 예상 지원금. [이 금액으로 상담 접수하기] |
| 04 | 상담 접수 | 이름, 전화번호, [신청하기] | 맨 위에 계산 결과 요약 카드(요금제, 남은 약정, 총 예상 지원금, [수정]). 이름, 전화번호, 설치 희망 지역, 상담 희망 시간(오전/오후/저녁), 필수 개인정보 동의 |
| 05 | 상담원 어드민 | 없음 (메신저·스프레드시트로 넘겨받는다고 가정) | 왼쪽 메뉴(접수 관리, 지원금 지급). 상태 탭(전체/접수/상담중/개통완료/취소)과 검색. 목록 열: 접수번호, 접수일, 고객(번호 가림), 요금제, 예상 지원금, 변형, 상태. 상세 패널: 고객·요금제·실험 변형, 상태 변경 버튼, 지원금 지급 처리 |

## 예외 케이스
| 화면 | 상황 | 동작 |
|---|---|---|
| 01 | 같은 방문자 재방문 | 실험 하나에서 항상 같은 변형을 보여 준다 |
| 01 | 변형 배정 실패 | A안을 보여 주고 실험 집계에서 뺀다 |
| 02 | 필터 결과 0건 | "조건에 맞는 요금제가 없어요"와 [필터 초기화] |
| 02·03 | 지원금 기준표에 없는 요금제 | 금액 대신 "지원금 상담 시 안내". 계산 버튼은 숨긴다 |
| 02·03 | 카드 금액과 계산 결과 | 같은 지원금 기준표를 쓴다. 숫자가 달라지면 안 된다 |
| 03 | 위약금이 보전 한도를 넘음 | 30만 원까지만 더하고 "최대 30만 원까지 보전돼요"를 보여 준다 |
| 03 | 약정 없음 | 개월 수와 위약금 입력을 숨기고 보전액은 0원 |
| 03 | 남은 개월 수가 0~36 밖 | 입력칸 오류, 결과를 숨긴다 |
| 04 | 7일 안에 같은 번호로 재접수 | 기존 접수에 합치고 "이미 접수된 상담이 있어요. 새 내용으로 업데이트했어요" |
| 04 | 계산 없이 들어옴 | 요약 카드 대신 [지원금 먼저 계산해 보기] 링크. 접수는 할 수 있다 |
| 04 | 전화번호 형식 오류, 필수 동의 안 함 | 입력칸 오류, 접수 버튼 비활성 |
| 05 | 거꾸로 가는 상태 변경 | 갈 수 없는 상태의 버튼은 비활성 (개통완료·취소는 끝 상태) |
| 05 | 개통 전 취소 | 지원금을 산정하지 않고 지급 버튼을 숨긴다 |
| 05 | 합쳐진 재접수 | "재접수 N회" 뱃지 |
| 05 | 전화번호 보기 | 기본은 가운데를 가린다. [보기]를 누르면 누가 봤는지 기록한다 |
| 05 | 지급 처리 | 실제 송금 없이 "지급 완료" 상태만 기록한다 |

## Phase D(도메인 설계)로 넘길 것
- 새로 나온 값: 위약금 보전 한도 30만 원, 남은 약정 입력 범위 0~36개월, 상담 희망 시간대, 설치 희망 지역
- 새로 나온 규칙: 전화번호 열람 기록, 변형 배정 실패 시 집계 제외
- 용어 후보: 예상 지원금, 기본 지원금, 위약금 보전액, 재접수
