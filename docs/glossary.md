## 작성 규칙
- **한 용어에 정의 하나.** 같은 말이 두 뜻으로 쓰이면 둘 중 하나에 다른 이름을 붙입니다.
- **영문 표기는 코드 이름 그대로.** 타입·클래스는 `PascalCase`, 필드·함수는 프로젝트 규칙을 따릅니다.
- **정의는 한두 문장.** 무엇이고, 언제 생기고, 누가 갖는지. 숫자·범위가 있으면 적습니다.
- **쓰지 않는 말:** 같은 뜻으로 섞여 쓰일 만한 말을 적습니다. 비우려면 `—`.
- **[가정]:** 실제 데이터 없이 정한 값에 붙입니다. 나중에 다시 정합니다.
- **구역별로 표를 나눕니다.** 제목에 구역 이름을 적습니다 (예: `## 1. 주문 (`order`)`).
- **이벤트 이름**은 과거형 영문 표기로, 마지막 절 "이벤트"에 모읍니다.
