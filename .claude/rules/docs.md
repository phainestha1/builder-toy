# 문서

- **`_docs/PLAN.md`:** 전체 플랜입니다. 사용자 결정이 바뀌면 7절 "확정한 결정"과 관련 절을 함께 고칩니다.
- **`docs/board.md`:** 멀티 세션 작업 보드입니다.
  - Orchestrator만 고칩니다. Builder와 Checker는 변경 내용을 Orchestrator에게 보냅니다.
  - 작업을 추가할 때는 완료 기준을 반드시 적습니다.
- **`docs/decisions/`:** 확정한 결정(ADR)입니다. AI가 참조하는 문서라서 결론과 규칙만 짧게 씁니다.
  - 파일 이름: `NNNN-제목.md`
  - 형식: 맥락 / 결정 / 결과
- **`docs/design/`:** 사람이 읽는 논의, 대안, 버린 이유를 적습니다. `decisions/`와 섞지 않습니다.
- **문체:** 한국어로 씁니다. 쉬운 말로 쓰고, 영어 약어는 처음 나올 때 풀어 씁니다.
