# 문서

- **`docs/board.md`:** 멀티 세션 작업 보드이자 진실의 원천입니다.
  - Orchestrator만 고칩니다. Builder와 Checker는 변경 내용을 Orchestrator에게 보냅니다.
  - 작업을 추가할 때는 완료 기준을 반드시 적습니다.
  - 진척과 결정은 "결정 로그"에, 작업별 시간과 검증 기록은 "운영 기록"에, 낮음 지적은 "후속 과제"에 남깁니다. 별도의 진행 문서를 만들지 않습니다.
- **`docs/decisions/`:** 확정한 결정(ADR)입니다. AI가 참조하는 문서라서 결론과 규칙만 짧게 씁니다.
  - 파일 이름: `NNNN-제목.md` (형식은 `0000-template.md`)
  - 형식: 맥락 / 결정 / 결과
  - 결정이 바뀌면 고치지 않고 새 ADR로 남기고, 앞 ADR의 상태를 "대체됨"으로 바꿉니다.
- **`docs/design/`:** 사람이 읽는 논의, 대안, 버린 이유를 적습니다. `decisions/`와 섞지 않습니다.
- **`docs/checklists/`:** 작업별 설계 체크리스트입니다. 형식은 `_template.md`.
- **`docs/retro.md`:** 측정 항목과 회고입니다. 사이클을 몇 번 돌린 뒤 운영 기록을 모아 봅니다.
- **도구를 늘리는 기준:** 같은 마찰이 **두 번** 생기면 그때 커맨드, 규칙, 훅, 서브에이전트를 추가합니다. 첫 번째는 `docs/retro.md`의 "마찰 기록"에 적어 두기만 합니다. 처음부터 늘리지 않습니다.
- **문체:** 한국어로 씁니다. 쉬운 말로 쓰고, 영어 약어는 처음 나올 때 풀어 씁니다.
